# SWYNEX Task 3 – Interactive Dashboard

## Project Overview
Online Retail Sales Analysis Dashboard created using Power BI.

## Objective
To analyze online retail sales, quantity, invoice counts, and product performance through interactive visuals.

## Dashboard Features
- Total Sales KPI
- Total Quantity KPI
- Unique Invoices KPI
- Unique Products/Descriptions KPI
- Top 10 Products by Sales
- Sales by Country
- Daily Sales Trend
- Top 10 Products by Quantity
- Country and Description slicers

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- UCI Online Retail Dataset

## Key Insight
The United Kingdom contributed the largest share of sales in the analyzed dataset.
